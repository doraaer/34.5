2. Tenant says: \"My radiators aren't heating properly.\" DORA asks a couple of useful questions, not the address already in Centrix.
3. Tenant states their availability and authorizes one or more booking windows. DORA says it will check with the maintenance company.

6. Back to `/partner`: start work, mark completed, provide service report and example invoice.
7. Open `/centrix`: same case ID, property/unit, partner, completed status, service report and invoice.
8. Explain generic connector: services, eligibility, availability, job request and status updates.
9. Mention mock partner, mock Centrix, real voice integration status honestly. Close with the fewer calls and forms needed to complete the repair.
